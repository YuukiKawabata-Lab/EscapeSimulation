# EscapeSimulationプログラムの挙動

## シミュレーションの概要
このプログラムは、危険エリアからの避難行動をシミュレートし、被験者の反応や行動パターンを分析するためのシステムです。

## メインフロー

### 1. シミュレーション初期化
1. `MainScene.cs`によってシーンが初期化されます
2. シミュレーションパラメータの設定
   - 刺激の表示間隔
   - 危険エリアの配置
   - 移動速度の初期値
3. 被験者（Cricket）の初期位置の設定

### 2. 刺激提示システム
1. `Stimulus.cs`による刺激の制御
   - 通常状態（stimulus.png）と警告状態（stimulusRed.png）の切り替え
   - 刺激表示のタイミング制御
   - 刺激位置の動的な更新

### 3. 危険エリア管理
1. `DangerArea.cs`による危険エリアの制御
   - エリア内の危険レベルの管理
   - 被験者との接触判定
   - 警告表示の制御

2. 脱出処理
   - `ExitDangerArea.cs`: エリアからの脱出ロジック
   - `ExitDangerRoad.cs`: 道路からの脱出処理
   - 最適な脱出経路の計算と提示

### 4. 被験者の行動制御
1. `Cricket.cs`による移動制御
   - キーボード入力による移動
   - 速度パラメータの適用
   - 衝突判定と移動制限

2. 衝突検知システム
   - `Collider.cs`による他オブジェクトとの干渉チェック
   - 壁や障害物との衝突処理
   - 危険エリアとの接触判定

### 5. データ収集と保存
1. `CsvSave.cs`によるデータ記録
   - 移動軌跡の記録
   - 刺激への反応時間
   - 危険エリアでの滞在時間
   - 脱出経路の選択

2. ファイル管理
   - `FileManeger.cs`: ファイルシステムの基本操作
   - `FileReadWrite.cs`: データの読み書き処理
   - CSVフォーマットでのデータ保存

## ユーザーインターフェース

### 1. パラメータ調整
- `FID_Slider.cs`によるスライダーUI
  - 刺激強度の調整
  - 表示間隔の設定
  - 危険レベルの調整

### 2. 速度制御
- `Speed_Input.cs`による速度パラメータ設定
  - 移動速度の入力
  - 値の検証
  - リアルタイムでの速度更新

### 3. メニュー操作
- `Menu.cs`によるメニュー制御
  - シミュレーション開始/停止
  - パラメータリセット
  - データ保存操作

## データ形式

### 1. 記録データ
```csv
TimeStamp,Position_X,Position_Y,Stimulus_State,DangerArea_Contact,Reaction_Time
```
- TimeStamp: 記録時のタイムスタンプ
- Position_X/Y: 被験者の座標
- Stimulus_State: 刺激の状態
- DangerArea_Contact: 危険エリアとの接触状態
- Reaction_Time: 刺激に対する反応時間

### 2. 設定データ
```json
{
  "simulation": {
    "stimulus_interval": 1000,
    "danger_level": 3,
    "movement_speed": 5
  },
  "display": {
    "resolution": "1920x1080",
    "refresh_rate": 60
  }
}
```

## エラー処理
1. 衝突検知エラー
   - 境界チェック
   - 無効な移動の防止
   - エラーログの記録

2. ファイル操作エラー
   - 保存先ディレクトリの存在確認
   - ファイルアクセス権限の確認
   - エラー時の自動バックアップ

3. パラメータ検証
   - 入力値の範囲チェック
   - 無効な設定の防止
   - デフォルト値へのフォールバック

## 注意事項
1. パフォーマンス
   - 高頻度な衝突判定による負荷
   - 大量データ保存時のメモリ使用
   - フレームレート低下への対策

2. データ保存
   - 定期的な自動保存の実施
   - バックアップファイルの作成
   - 長時間実験での容量管理

3. 実験環境
   - ディスプレイのリフレッシュレート設定
   - 入力デバイスの応答性確認
   - システムリソースの確保
